# API Reference

This reference is generated from the source docstrings. It focuses on the **public** classes you use to connect to a device and drive services.

New to the library? Read the [Python API guide](https://doronz88.github.io/pymobiledevice3/latest/guides/python-api/index.md) first — it shows the connect-then-use-a-service pattern with runnable examples. This section is the detailed lookup.

- **[Connecting to a device](https://doronz88.github.io/pymobiledevice3/latest/api/connection/index.md)** — lockdown clients, RemoteServiceDiscovery, no-root tunnels, tunneld.
- **[Lockdown services](https://doronz88.github.io/pymobiledevice3/latest/api/services/index.md)** — the `LockdownService` base class and the most-used services.
- **[System & device](https://doronz88.github.io/pymobiledevice3/latest/api/system/index.md)** — activation, notifications, power, recovery, companion.
- **[Apps, files & profiles](https://doronz88.github.io/pymobiledevice3/latest/api/apps-files/index.md)** — house arrest, configuration and provisioning profiles.
- **[Capture, logging & automation](https://doronz88.github.io/pymobiledevice3/latest/api/capture/index.md)** — screenshots, pcap, syslog, WebInspector, WDA.
- **[Backup, symbols & location](https://doronz88.github.io/pymobiledevice3/latest/api/backup-symbols/index.md)** — backup/restore, symbol fetching, GPS simulation.
- **[Developer / DVT](https://doronz88.github.io/pymobiledevice3/latest/api/dvt/index.md)** — the DVT provider and instruments (iOS 17+, over a tunnel).
