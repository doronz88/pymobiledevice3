    pymobiledevice3 profile¶

    Install and remove configuration profiles, supervise the device, and other MDM-style management.

    list¶

    Print the installed configuration profiles.

    pymobiledevice3 profile list [OPTIONS]

    Options:

    Option Description
    --native macOS only: reach the iOS 17+ tunnel by piggybacking Apple's own remoted tunnel via the remotepairingd service. NO root, no entitlement, no Xcode. Rides Apple's kernel-routable tunnel, so throughput matches the kernel tunnel, but the device keeps a single RSD connection on it: remoted and this process evict each other's, which can reset connections and leave Xcode/devicectl without the device until remoted reconnects. Mutually exclusive with --rsd/--tunnel/--userspace. [env var: PYMOBILEDEVICE3_NATIVE]

    Accepts the connection options: --rsd, --tunnel, --userspace, --mobdev2, --usbmux, --udid.

    install¶

    Install configuration profiles (.mobileconfig).

    Without --keybag the device asks the user to approve each profile; with a supervision identity (supervised devices) it is installed silently.

    pymobiledevice3 profile install [OPTIONS] {profiles}...

    Arguments:

    Argument Description
    profiles... <list[Path]> Configuration profile files (.mobileconfig). [required]

    Options:

    Option Description
    --native macOS only: reach the iOS 17+ tunnel by piggybacking Apple's own remoted tunnel via the remotepairingd service. NO root, no entitlement, no Xcode. Rides Apple's kernel-routable tunnel, so throughput matches the kernel tunnel, but the device keeps a single RSD connection on it: remoted and this process evict each other's, which can reset connections and leave Xcode/devicectl without the device until remoted reconnects. Mutually exclusive with --rsd/--tunnel/--userspace. [env var: PYMOBILEDEVICE3_NATIVE]
    --keybag <file> Supervision identity (PEM with the supervisor certificate and private key) to install silently; without it the user must approve the profile on the device.

    Accepts the connection options: --rsd, --tunnel, --userspace, --mobdev2, --usbmux, --udid.

    erase-device¶

    Erase all content and settings from the device. DESTRUCTIVE.

    Wipes the device back to factory state (like Settings > General > Transfer or Reset > Erase All Content and Settings). There is no confirmation.

    pymobiledevice3 profile erase-device [OPTIONS]

    Options:

    Option Description
    --native macOS only: reach the iOS 17+ tunnel by piggybacking Apple's own remoted tunnel via the remotepairingd service. NO root, no entitlement, no Xcode. Rides Apple's kernel-routable tunnel, so throughput matches the kernel tunnel, but the device keeps a single RSD connection on it: remoted and this process evict each other's, which can reset connections and leave Xcode/devicectl without the device until remoted reconnects. Mutually exclusive with --rsd/--tunnel/--userspace. [env var: PYMOBILEDEVICE3_NATIVE]
    --preserve-data-plan / --no-preserve-data-plan Keep the eSIM / cellular data plan across the erase. [default: preserve-data-plan]
    --disallow-proximity-setup / --no-disallow-proximity-setup Prevent setting up the erased device from a nearby device (Quick Start). [default: no-disallow-proximity-setup]

    Accepts the connection options: --rsd, --tunnel, --userspace, --mobdev2, --usbmux, --udid.

    create-keybag¶

    Create a supervision identity (keybag) for supervise and silent profile installs.

    Runs locally; no device needed.

    pymobiledevice3 profile create-keybag [OPTIONS] {keybag} {organization}

    Arguments:

    Argument Description
    keybag <file> File to write the new identity (PEM private key + certificate) to. [required]
    organization <str> Organization name for the certificate's Common Name. [required]

    supervise¶

    Supervise the device under your organization.

    Activates the device first if it is not activated yet, then writes a supervised cloud configuration that registers the supervision identity.

    pymobiledevice3 profile supervise [OPTIONS] {organization}

    Arguments:

    Argument Description
    organization <str> Organization name shown on the device as the supervisor. [required]

    Options:

    Option Description
    --native macOS only: reach the iOS 17+ tunnel by piggybacking Apple's own remoted tunnel via the remotepairingd service. NO root, no entitlement, no Xcode. Rides Apple's kernel-routable tunnel, so throughput matches the kernel tunnel, but the device keeps a single RSD connection on it: remoted and this process evict each other's, which can reset connections and leave Xcode/devicectl without the device until remoted reconnects. Mutually exclusive with --rsd/--tunnel/--userspace. [env var: PYMOBILEDEVICE3_NATIVE]
    --keybag <file> Supervision identity to register (see create-keybag). If omitted, a throwaway one is generated, so later supervised-only commands cannot be used.

    Accepts the connection options: --rsd, --tunnel, --userspace, --mobdev2, --usbmux, --udid.
