    pymobiledevice3 lockdown¶

    Pair/unpair, read and change device values, and talk to raw lockdown services.

    recovery¶

    Reboot the device into recovery mode.

    The device leaves normal iOS and waits in recovery; use restore exit to boot it back normally.

    pymobiledevice3 lockdown recovery [OPTIONS]

    Options:

    Option Description
    --native macOS only: reach the iOS 17+ tunnel by piggybacking Apple's own remoted tunnel via the remotepairingd service. NO root, no entitlement, no Xcode. Rides Apple's kernel-routable tunnel, so throughput matches the kernel tunnel, but the device keeps a single RSD connection on it: remoted and this process evict each other's, which can reset connections and leave Xcode/devicectl without the device until remoted reconnects. Mutually exclusive with --rsd/--tunnel/--userspace. [env var: PYMOBILEDEVICE3_NATIVE]

    Accepts the connection options: --rsd, --tunnel, --userspace, --mobdev2, --usbmux, --udid.

    set¶

    Change a lockdown value on the device.

    VALUE is parsed as a Python literal (with ast.literal_eval), so quote strings, e.g. "'My iPhone'".

    pymobiledevice3 lockdown set [OPTIONS] {value} [domain] [key]

    Arguments:

    Argument Description
    value New value as a Python literal (e.g. True, 42, 'text'). [required]
    domain Value domain; omit for the global domain.
    key Key to set.

    Options:

    Option Description

    start-tunnel¶

    Start an iOS 17.4+ tunnel over lockdown and print its --rsd HOST PORT (needs root).

    Rarely needed: commands build their own no-root tunnel. Use it when another process needs --rsd. Always uses TCP. Runs until Ctrl+C.

    pymobiledevice3 lockdown start-tunnel [OPTIONS]

    Options:

    Option Description
    --native macOS only: reach the iOS 17+ tunnel by piggybacking Apple's own remoted tunnel via the remotepairingd service. NO root, no entitlement, no Xcode. Rides Apple's kernel-routable tunnel, so throughput matches the kernel tunnel, but the device keeps a single RSD connection on it: remoted and this process evict each other's, which can reset connections and leave Xcode/devicectl without the device until remoted reconnects. Mutually exclusive with --rsd/--tunnel/--userspace. [env var: PYMOBILEDEVICE3_NATIVE]
    --script-mode / --no-script-mode Print only HOST and port, for parsing from shell scripts. [default: no-script-mode]

    Accepts the connection options: --rsd, --tunnel, --userspace, --mobdev2, --usbmux, --udid.

    remotepairing¶

    Print the device's RemotePairing handshake info; with --pair, also pair.

    Performs a RemotePairing handshake over the com.apple.dt.remotepairingdeviced.lockdown control channel and prints the device's handshake info (peer device info, wire protocol versions, pairing capabilities). This control channel does not create tunnels - use start-tunnel for that.

    With --pair, performs RemotePairing pair-setup when the device is not already paired. Because this runs over the already-trusted lockdownd (USB) transport, pairing is promptless - no Trust dialog is shown - and it writes the RemotePairing pair record used by pymobiledevice3 remote start-tunnel, letting you bootstrap that record over USB without any on-device interaction.

    pymobiledevice3 lockdown remotepairing [OPTIONS]

    Options:

    Option Description
    --native macOS only: reach the iOS 17+ tunnel by piggybacking Apple's own remoted tunnel via the remotepairingd service. NO root, no entitlement, no Xcode. Rides Apple's kernel-routable tunnel, so throughput matches the kernel tunnel, but the device keeps a single RSD connection on it: remoted and this process evict each other's, which can reset connections and leave Xcode/devicectl without the device until remoted reconnects. Mutually exclusive with --rsd/--tunnel/--userspace. [env var: PYMOBILEDEVICE3_NATIVE]
    --pair Perform RemotePairing pair-setup if not already paired (promptless over lockdownd).
    --raw Do not decode the base64 deviceKVSData blob.

    Accepts the connection options: --rsd, --tunnel, --userspace, --mobdev2, --usbmux, --udid.
