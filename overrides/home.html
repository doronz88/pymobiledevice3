pymobiledevice3

Talk to iPhones and iPads from any computer.

A pure-Python CLI and API for iOS devices: logs, files, apps, crash reports, packet capture, WebInspector and the full developer toolchain, including iOS 17+ tunnels built in-process. Windows, Linux and macOS. No Xcode, no root.

$ python3 -m pip install -U pymobiledevice3
Get started CLI recipes Python API 
# every connected device, USB or Wi-Fi
$ pymobiledevice3 usbmux list
# live device logs
$ pymobiledevice3 syslog live
# iOS 17+ developer services, no sudo
$ pymobiledevice3 developer dvt screenshot shot.png
# debug Safari from Chrome DevTools
$ pymobiledevice3 webinspector cdp
